# Термины и сокращения

| Термин | Расшифровка и смысл |
|---|---|
| Synthetic pre-credit margin | Синтетическая маржа до кредитного риска: `margin_anchor + lambda × (product_rate_proxy − weighted_product_rate)`. |
| Margin anchor | Якорь средней маржи периода; средневзвешенный уровень синтетической маржи портфеля. |
| Lambda (`lambda`) | Коэффициент передачи различий pricing proxy в продуктовую маржу. |
| Pricing proxy | Рыночный показатель-заменитель ставки; не является фактической доходностью накопленного портфеля ВТБ. |
| Weighted pricing proxy | Средневзвешенный pricing proxy по текущим продуктовым экспозициям. |
| RAR | Risk-adjusted rate — риск-скорректированная ставка: синтетическая маржа минус стоимость кредитного риска. |
| RAFR | Risk-adjusted financial result — финансовый результат с учётом риска за шесть месяцев: экспозиция × RAR × 0,5. Не является прибылью или RAROC. |
| Critical margin | Критическая маржа продукта, при которой совокупный RAFR портфеля достигает заданной границы, сейчас нуля. |
| Required margin premium vs Mortgage | Требуемая премия маржи относительно ипотеки: критическая маржа продукта минус текущая синтетическая маржа ипотеки. |
| Critical share | Вспомогательная критическая доля продукта при замещении ипотеки; больше не является главным результатом. |
| Credit cost | Годовая стоимость кредитного риска, используемая как вход `MODEL_DATA`. |
| Exposure | Экспозиция — объём кредитных требований по продукту, млрд руб. |
| Base / Moderate / Severe | Базовый / умеренный / тяжёлый сценарий. |
| Portfolio-mix sensitivity | Чувствительность к продуктовому составу при фиксированной общей экспозиции. |
| Reverse stress | Обратное стресс-тестирование: поиск значения параметра, при котором достигается критическая граница. |
| FACT | Опубликованный факт или исходный показатель из публичных материалов. |
| MARKET PROXY | Внешний рыночный показатель-заменитель. |
| SYNTHETIC | Синтетическая величина, построенная по модельной формуле. |
| MODEL ASSUMPTION | Явная модельная предпосылка, включая `lambda` и стрессовые сдвиги. |
| CALCULATED | Рассчитанный результат, включая RAFR и критическую маржу. |
| ECL | Expected credit losses — ожидаемые кредитные убытки. |
| NIM | Net interest margin — чистая процентная маржа. |
| RAROC | Risk-adjusted return on capital — доходность капитала с учётом риска; в модели не рассчитывается. |
| RWA | Risk-weighted assets — активы, взвешенные по риску; в модели не рассчитываются. |
| Opex | Operating expenses — операционные расходы; в модели не рассчитываются. |
| NA | Not available — порог не представлен; причина указана в статусе. |
| п.п. / bp | Процентный пункт / basis point (базисный пункт); 100 bp = 1 п.п. |

Продукты: Mortgage — ипотека; Consumer — потребительские кредиты; Auto — автокредиты; Cards — кредитные карты. Технические имена сохраняются для воспроизводимости.
