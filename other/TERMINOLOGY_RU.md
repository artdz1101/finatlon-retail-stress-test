# Термины и сокращения

| Термин | Смысл |
|---|---|
| Exposure | Экспозиция — объём кредитных требований, млрд руб. |
| ECL | Expected credit losses — ожидаемые кредитные убытки. |
| ECL rate | Резерв ECL / экспозиция: показатель запаса на дату. |
| Credit cost (CC) | Годовой потоковый исследовательский показатель стоимости кредитного риска. |
| CoR | Cost of risk — стоимость риска; официальный показатель группы отличается от исследовательского продуктового CC. |
| Pricing / funding | Внешняя ставка по кредиту / внешний показатель стоимости фондирования. |
| CRAS | Credit-risk-adjusted spread — годовой спред с учётом риска: pricing − funding − CC. |
| RAFR | Risk-adjusted financial result — финансовый результат с учётом риска за шесть месяцев: exposure × CRAS × 0,5. |
| CreditLoss | Модельные кредитные потери: exposure × CC × 0,5. |
| Product-mix sensitivity | Чувствительность к составу: один продукт растёт за счёт ипотеки, остальные два фиксированы. |
| Marginal effect | Предельный эффект: изменение RAFR или потерь на +1 п.п. доли продукта. |
| Critical share | Критическая доля: первое допустимое пересечение RAFR = 0 в сторону ухудшения от исходной доли вверх. |
| Adverse crossing | Пересечение критической границы в сторону ухудшения результата. |
| Reverse stress | Обратный стресс: поиск параметра достижения критической границы. |
| Portfolio credit-cost multiplier | Множитель текущего CC всех продуктов данного сценария, при котором RAFR = 0. |
| Break-even credit cost | Стоимость риска для безубыточности продукта; вспомогательная диагностика. |
| Base / Moderate / Severe | Базовый / умеренный / тяжёлый стресс стоимости риска при фиксированных pricing и funding. |
| FACT | Независимо сверенный опубликованный факт; компоненты ВТБ с открытой сверкой не получают этот статус. |
| MARKET PROXY | Внешний рыночный показатель-заменитель; 17,8% ипотека относится к этой категории. |
| SYNTHETIC | Синтетический портфель: сочетание публичных калибровочных ориентиров с внешними ставками. |
| MODEL ASSUMPTION | Модельное предположение; PROVISIONAL означает предварительный статус. |
| CALCULATED | Расчётная величина: CC, CRAS, RAFR, потери, эффекты и пороги. |
| PENDING | Сверка с первоисточником ещё не завершена. |
| NA | Not available — порог не представлен; причина в статусе. |
| Grace period / utilization | Льготный период / использование кредитного лимита. |
| Interchange | Межбанковское вознаграждение по карточным операциям. |
| Transactors / revolvers | Клиенты с полным погашением долга / переносом процентного остатка. |
| NIM / FTP | Чистая процентная маржа / внутреннее трансфертное ценообразование фондирования; не восстанавливаются. |
| RWA / RAROC | Активы, взвешенные по риску / доходность капитала с учётом риска; не рассчитываются. |
| Opex | Операционные расходы; не включены. |
| QA | Quality assurance — проверка качества. |
| bp / п.п. | Базисный / процентный пункт: 100 bp = 1 п.п. = 0,01 доли единицы. |

Mortgage — ипотека; Consumer — потребительские кредиты; Auto — автокредиты; Cards — кредитные карты.

Ставки и доли в CSV выражены в долях единицы. ΔRAFR и ΔCreditLoss на +1 п.п. — млрд руб. за шесть месяцев. В отчёте доли/ставки показаны в процентах.
